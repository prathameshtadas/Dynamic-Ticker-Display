# Dynamic Ticker Display

A digital ticker-display project based on an FPGA implementation. The project is intended to demonstrate real-time scrolling or changing text on a hardware display.

## Project Overview

The ticker continuously updates displayed information, making it suitable for announcements, status messages, or other short real-time text.
